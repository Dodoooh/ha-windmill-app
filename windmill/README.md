# Home Assistant Add-on: Windmill

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

[Windmill](https://www.windmill.dev/) is an open-source developer platform
and workflow engine to build internal tools, scripts, flows and apps. This
add-on packages a single-instance Windmill (server + worker + bundled
PostgreSQL) for Home Assistant Operating System.

After starting the add-on, open the **Web UI** button. The default login is

- **Email:** `admin@windmill.dev`
- **Password:** `changeme`

Change it from the Windmill UI immediately after the first login.

See [DOCS.md](./DOCS.md) for configuration details.
